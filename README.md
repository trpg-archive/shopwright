# Shopwright v1.0.8

Shopwright — модуль магазинов для Foundry VTT 13/14 и системы dnd5e 5.2.5/5.3.3. Модуль полностью разработан с помощью ИИ.

Магазины используют UUID исходных Item-документов, а не создают их копии. Один актёр может использоваться для любого количества токенов-магазинов, а сами токены связываются с нужной витриной независимо друг от друга.

## Возможности

- менеджер магазинов с категориями и поиском;
- товары и услуги из мира и компендиумов;
- покупка и продажа нескольких единиц;
- собственный кошелёк торговца и настраиваемая скупка;
- разрешённые валюты, сдача и публичные либо приватные чеки;
- товарные группы, формулы пополнения и списания, максимальный остаток и отдельная наценка;
- ленивое обновление ассортимента по игровому времени Foundry;
- безопасный предпросмотр описаний предметов;
- история торговых операций;
- токены-витрины с открытием магазина двойным щелчком;
- импорт и экспорт магазинов, категорий и истории;
- сортировка ассортимента по названию, цене и количеству;
- быстрый переход из витрины в редактор для мастера;
- светлая, тёмная, холодная и системная темы интерфейса.

## Установка

### Через Foundry VTT

1. Откройте **Setup → Add-on Modules → Install Module**.
2. В поле **Manifest URL** вставьте:

   `https://github.com/trpg-archive/shopwright/releases/latest/download/module.json`

3. Нажмите **Install** и после установки включите Shopwright в настройках мира.

### Вручную

1. Скачайте ZIP нужной версии со страницы GitHub Releases.
2. Распакуйте папку `shopwright` в `Data/modules/`.
3. Проверьте наличие файла `Data/modules/shopwright/module.json`.
4. Запустите Foundry и включите Shopwright в настройках мира.

После обновления модуля перезагрузите страницы мастера и игроков через `Ctrl + F5`. У всех подключённых участников должна использоваться одна версия модуля.

Shopwright использует собственное пространство настроек и флагов `shopwright`. Данные прежних тестовых сборок с другим ID автоматически не переносятся.

## Работа с токенами

Выберите токен на сцене, откройте «Менеджер магазинов» и привяжите к нему нужный магазин. Обычный двойной щелчок по привязанному токену открывает витрину. `Shift + двойной щелчок` оставляет штатное действие Foundry и открывает лист актёра.

Имя и изображение токена могут подхватываться из магазина. Актёр и его прототип токена при этом не изменяются.

## Покупки, продажи и кошелёк

Для сетевых операций, инициированных обычным игроком, в мире должен находиться активный мастер с той же версией Shopwright. Клиент мастера автоматически проверяет и выполняет запрос; отдельное подтверждение не требуется.

При включённом собственном кошельке магазин не сможет выкупить предметы дороже доступного баланса. Покупки и услуги могут пополнять этот кошелёк на точную стоимость операции, а выплаты за проданные предметы уменьшают баланс. Все изменения записываются в историю.

## Товарные группы и обновление ассортимента

Для товарной группы можно настроить период в игровых часах, днях или неделях, формулу пополнения, формулу списания, максимальный остаток и отдельную наценку. Обновление использует `game.time.worldTime` и выполняется лениво при открытии магазина. Если с прошлого обновления прошло один или несколько периодов, Shopwright применяет ровно один цикл и начинает новый отсчёт от текущего времени мира. Игрок обращается к мастеру только когда локальная проверка показывает, что обновление действительно требуется.

Итоговая автоматическая цена рассчитывается так:

```text
базовая цена предмета
× общая наценка магазина
× наценка товарной группы
```

Поле «Своя цена» у отдельного товара имеет приоритет над коэффициентами.

## Импорт и экспорт

Во вкладке «Импорт и экспорт» можно скачать магазины вместе с категориями, отдельно сохранить историю или создать полную резервную копию. При импорте магазины можно добавить как новые либо полностью заменить текущие данные; историю можно дополнить без повторов или заменить целиком.

Резервная копия сохраняется в версионированном формате `shopwright-backup`. Ссылки на товары и услуги остаются UUID, поэтому при переносе в другой мир соответствующие документы и компендиумы должны быть доступны под прежними адресами.

## Публичный API

```js
game.shopwright.openManager();
game.shopwright.openShop(shopId);
game.shopwright.getShops();
game.shopwright.bindSelectedToken(shopId);
```
